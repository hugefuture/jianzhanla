钩子驱动的插件内核

插件可以声明菜单、接口、前端页面与事件钩子，安装瞬间全部就位；卸载即清理，主程序零污染。

  • 登录成功 / 失败、公告发布等事件钩子埋点，payload 链式改写

  • 配置项按 JSON Schema 动态渲染表单，类型自动转换
  • 单个插件异常自动隔离，不影响主流程

OTA UPGRADE

后台一键远程升级

产品迭代不再 FTP 传包：检查更新 → 下载 → 校验 → 备份 → 落盘 → 执行 SQL → 回写版本，全链路自动，出问题一键回滚。

  • sha256 + HMAC 双重签名校验，杜绝升级包被篡改
  • 路径白名单 + 防 Zip Slip 路径穿越攻击
  • 危险 SQL 拦截（drop database / grant 等）
  • 升级前自动备份，支持「仅文件」/「含数据库」两档回滚
  • 升级日志独立成表，回滚后审计链依然完整
# 发布：本地一键打升级包
$ php tools/make-upgrade-package.php --version=1.2.0

# 产物推到升级源（任意静态 HTTP 服务）
tools/upgrade-repo/
├── manifest.json              # 版本清单（含 sha256）
└── jianzhanla-admin-1.2.0.zip

# 后台：系统管理 → 系统升级 → 检查更新
✔ 拉取清单    ✔ 签名校验
✔ 下载安装包  ✔ 自动备份
✔ 文件落盘    ✔ 执行 SQL
✔ 升级完成：1.1.0 → 1.2.0（可一键回滚）

三分钟跑起来

克隆、导入、启动 —— Windows 双击批处理，Linux 三条命令。

# 1. 克隆仓库
git clone https://github.com/hugefuture/jianzhanla.git
cd jianzhanla-admin

# 2. 导入数据库（sql/init.sql 含演示数据）
mysql -uroot -p sdccc_admin < sql/init.sql

# 3a. Windows：双击 start-server.bat 一键启动
# 3b. Linux / macOS：
cd backend && php think run
cd frontend && npm install && npm run dev
